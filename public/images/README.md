# Photos à déposer

| Fichier | Emplacement |
|---|---|

| `client-claire.jpg`, `client-karim.jpg`, `client-julie.jpg` | Cartes parcours (carré) |

| `temoignage-1.jpg` à `temoignage-5.jpg` | Carrousel de témoignages |
