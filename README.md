# Site Envol 90 (Next.js)

Landing page codée : Next.js 15 (export statique), Tailwind 4, Motion, et deux composants React Bits (`LightRays`, `SpotlightCard`, licence MIT + Commons Clause).

```bash
npm install
npm run dev     # http://localhost:3000
npm run build   # export statique dans out/, déployable sur Vercel ou Netlify
```

Photos : déposez-les dans `public/images/` (noms attendus dans `public/images/README.md`).
